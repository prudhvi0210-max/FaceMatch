
# FaceMatch

AI-Based Face Recognition and Identity Matching System

## Project Overview
FaceMatch is a Python-based academic project that explores face recognition using computer vision, machine learning, and database technologies.

The application will allow users to register individuals, upload facial images, and search for possible matches among registered individuals.

## Main Features
- Person registration
- Face detection
- Face recognition using embeddings
- Similarity-based matching
- PostgreSQL database integration
- Experiments with masks, lighting, and face angles
- Experimental sketch-to-photo matching

## Technologies
- Python
- OpenCV
- Pretrained face-recognition model
- PostgreSQL
- FastAPI
- Streamlit

Activate the virtual environment and run:

```bash
python app/main.py
```

## Project Scope
FaceMatch is an academic prototype for evaluating identity matching using consented or appropriately sourced images. It does not determine guilt or provide definitive identification.
