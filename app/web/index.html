TRANSPARENT BY DESIGN

Know what a result means.

FaceMatch is a local academic prototype. Its results need human review.

01

The workflow

RetinaFace detects and aligns a single face. FaceNet512 produces a 512-value embedding, compared with registered photographs using cosine similarity.

02

The decision

The fixed experimental threshold is 0.50. Lower scores return unknown. Higher scores return a possible match, unless duplicate references or tied scores make the result ambiguous.

03

Your photographs

Query uploads are temporary. Registration explicitly saves a reference locally. No cloud service receives your photographs. Model weights may download on first use.

04

Validation still matters

Functional checks are not accuracy validation. Test genuinely new, consented photographs before making performance claims. The app does not establish identity or determine guilt.
